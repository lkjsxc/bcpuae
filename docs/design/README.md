## Design Principles

1. **Modal Clarity** — Current mode is always obvious
2. **Immediate Feedback** — Every action has visible response
3. **Graceful Degradation** — Works with or without TTY
4. **Minimal Surprise** — Vim-inspired where practical
5. **Performance** — No blocking operations in UI thread
